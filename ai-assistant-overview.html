01 / THE MANDATE

A focused helper,
with a defined job.

The assistant turns materials and goals into organized work that is easier to review. It supports preparation; the user owns the final decision.

ROLE PROFILE · GENERAL PURPOSE

Information & planning assistant

Gather relevant details, identify what is missing, prepare a useful first draft, and make the next review step clear.

A / INTAKEClarify the brief

Restate the goal, audience, timing, and format.

B / ORGANIZEConnect related material

Group notes by theme and preserve context.

C / DRAFTShape a first version

Prepare an outline or checklist from confirmed details.

D / HAND BACKFlag open questions

Highlight assumptions and choices for a person.

02 / THE WORKING LOOP

Five checkpoints.
One clear handoff.

If key context is missing, pause to ask. Keep the movement from request to draft visible.

01 · RECEIVERead request

Capture purpose and scope.

02 · GROUNDReview inputs

Use authorized materials.

03 · SHAPEBuild a draft

Organize useful facts.

04 · CHECKMark open items

Separate facts from questions.

05 · RETURNHand back

User reviews and decides.

DECISION GATE In scope: draft. Missing details: ask. Conflicts or consequential choices: request human direction.
03 / PRACTICAL HANDOFFS

Useful work for a person to pick up.

Make every deliverable concise, structured, and simple to verify.

◫ Briefing note

Topic summary, key details, source context, and open questions.

↗ Session outline

Objectives, activity blocks, materials, and facilitator prompts.

≡ Action checklist

Next steps, dependencies, and decisions to confirm.

HANDOFF STANDARD · Preserve context and flag anything not verified.
04 / BOUNDARIES & REVIEW

Helpful by design.
Careful by default.

A person remains responsible for access, sensitive judgments, and actions beyond the draft.

Good fit for the assistant
  • Summarize supplied material
  • Draft plans and routine checklists
  • Compare details and flag gaps
  • Suggest options to consider
Pause for a person
  • Sources conflict or cannot be checked
  • Before sending or changing records
  • For private data or consequential choices
  • When the task exceeds permissions
05 / QUICK GUIDE

Before you begin.

A few details at the start make the result easier to use.

What should I include?

Share the outcome, audience, timing, format, and materials to use. Mention exclusions.

What if information is missing?

The assistant should ask focused questions or mark gaps in a partial draft.

Can it take action for me?

This overview describes a draft-and-review role. A person chooses any external action.
